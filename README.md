## 🌟 Overview

**Brothers Regedit Roblox Midi Player** is a highly optimized, native C++ application that seamlessly reads standard MIDI files (`.mid`, `.midi`) and simulates the precise keystrokes required to play instruments flawlessly in Roblox. 

Featuring a stunning **"Liquid Glass" UI** built on top of Dear ImGui and DirectX 11, the application provides an immersive, translucent overlay experience that looks modern while taking virtually zero system resources. 

## ✨ Features

- **🎮 Flawless Roblox Integration:** Custom-built keystroke injection ensures every note is played perfectly on Roblox instruments without latency or dropped inputs.
- **💎 Premium "Liquid Glass" Aesthetic:** A fully custom transparent overlay UI powered by Windows DWM acrylic blur. It looks incredible and doesn't get in your way.
- **⚡ Global Hotkeys:** Set your own custom hotkeys to **Play/Pause**, **Stop**, and **Change Speed (+/-)** directly while playing Roblox—no need to Alt-Tab!
- **🎵 Advanced Queue & Library:** Drag-and-drop MIDI files directly into the app. Create a saved library, mark tracks as favorites (⭐), and shuffle your playlist.
- **📁 Windows Context Menu Integration:** Right-click any `.mid` or `.midi` file in Windows Explorer to instantly load it into the player.
- **🏎️ Variable Speed Control:** Play difficult tracks at your own pace with a precision slider or hotkeys to change playback speed from `0.1x` to `3.0x`.

## 🚀 Getting Started

### Prerequisites
- Windows 10 / 11 (required for the acrylic glass window effect)
- CMake & C++ Build Tools (if compiling from source)

### Installation

1. **Download the App:** Grab the latest executable from the Releases tab (or compile from source).
2. **Run it:** Open `RobloxMidiPlayer.exe`.
3. **Register Extension:** The app will automatically add a "Play with Brothers Regedit Roblox Midi Player" option to your right-click context menu for MIDI files.
4. **Load Tracks:** Drag and drop `.mid` files directly into the Dashboard or click "Upload MIDI File".
5. **Play in Roblox:** Equip your instrument in Roblox, set your hotkeys in the player's Settings tab, and press your Start hotkey!

## 🛠️ Compiling from Source

This project uses CMake and requires a C++ compiler supporting C++17 or higher.

```bash
# Clone the repository
git clone https://github.com/munishhhh/Roblox-Midi-Player.git
cd Roblox-Midi-Player

# Build the project
cmake -B build
cmake --build build --config Release
```

The compiled executable will be located in the `build/Release` or `build` folder.
